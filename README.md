# 随手新建

一款 macOS 右键新建文件工具。在桌面或 Finder 文件夹中，右键选择文件类型，即可创建并命名文件，方便随手记录、编写文档和复用常用模板。

## 支持什么

- 在桌面和 Finder 当前文件夹的空白处右键新建文件。
- 创建后直接输入文件名，按回车确认，默认保留扩展名。
- 自定义完整文件名，或选择已有普通文件作为模板。
- 同名文件自动添加序号，例如「未命名 2.txt」，保留已有文件。
- 使用系统文件类型图标，保留原有颜色。

| 类型 | 文件格式 |
| --- | --- |
| TXT | `.txt` |
| RTF | `.rtf` |
| XML | `.xml` |
| Word / WPS 文字 | `.docx` |
| Excel / WPS 表格 | `.xlsx` |
| PPT / WPS 演示 | `.pptx` |
| Markdown | `.md` |

当前安装包适用于 **Apple Silicon（M 系列芯片）和 macOS 13 或更新版本**，已在 macOS 26.4 验证。

## 使用范围

- 创建位置需要是具备写入权限的实际文件夹；搜索结果和「最近使用」等聚合视图不提供创建入口。
- 模板支持普通文件，不支持文件夹和应用包。
- WPS 入口使用 `.docx`、`.xlsx`、`.pptx` 标准格式。文件的默认打开应用及图标由 macOS 文件关联决定。

## 怎么用

1. 从 [Releases](https://github.com/haojiakui/suishou-newfile/releases/latest) 下载安装包，解压后将「随手新建.app」拖入「应用程序」，双击打开。
2. 点击「打开 Finder 扩展设置…」，启用「随手新建」。macOS 26 的入口通常位于「通用 → 登录项与扩展 → 扩展 → Finder」。
3. 在「隐私与安全性 → 辅助功能」中允许「随手新建」，授权后从菜单栏退出并重新打开应用。
4. 系统询问时，允许「随手新建」控制「访达」。此权限可在「隐私与安全性 → 自动化」中管理。
5. 回到桌面或 Finder 文件夹，在空白处右键，选择「新建文件 → 文件类型」，输入名称并按回车完成。

「自定义创建新文件…」用于输入带扩展名的完整名称。RTF、XML 和 Office 格式使用对应的文档内容，其余扩展名创建空白文件。

「从模板创建…」用于选择一个普通文件，将其内容复制到目标文件夹，适合复用文档、配置和代码模板。

应用驻留在菜单栏，可从菜单栏打开使用说明或退出。当前安装包采用本地 ad-hoc 签名，安装和扩展加载遵循 macOS 系统安全策略。

## 怎么卸载

1. 在系统设置中关闭「随手新建」Finder 扩展。
2. 从菜单栏退出「随手新建」。
3. 将「应用程序」中的「随手新建.app」移到废纸篓。
